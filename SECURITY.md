# Security Policy

## Reporting a Vulnerability
If you discover a security issue, please do not open a public issue. Instead, email `security@filipgrace.dev` with the details so we can address the problem quickly.

Please include:
- A description of the issue and potential impact
- Steps to reproduce or proof-of-concept code, if available
- Any suggested remediation ideas

You will receive an acknowledgement within five business days. Once the fix is ready, we will coordinate public disclosure.
